# دوره پیشرفته پایتون برای علم داده

صفحه تک‌صفحه‌ای حرفه‌ای لندینگ دوره آموزشی پیشرفته پایتون برای علم داده و هوش مصنوعی.

## ویژگی‌ها
- فارسی کامل + RTL
- طراحی Minimal Mono سیاه/سفید
- رسپانسیو کامل
- پشتیبانی dark/light mode
- آماده استقرار روی GitHub Pages
- ساختار تبدیل‌محور (هرو، سرفصل، مدرس، قیمت، CTA)

## نحوه فعال‌سازی GitHub Pages
Settings → Pages → Deploy from a branch → main / root
